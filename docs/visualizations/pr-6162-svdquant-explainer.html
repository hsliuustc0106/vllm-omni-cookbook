SVDQuant, visually

4-bit weights and 4-bit activations for diffusion transformers, kept accurate by a small BF16 low-rank residual that absorbs the parts that refuse to quantize. The name is literal: singular value decomposition, applied per linear layer at quantization time.

y  =  Qw4(W · diag(s)) · Qa4(x / s)  +  U (VT·x)  +  b
//  teal = 4-bit tensor-core branch  ·  amber = BF16 rank-r correction (r ≪ K)

Everything below is interactive and computed live in your browser — the SVD demo runs a real power-iteration decomposition on a synthetic matrix with channel outliers.

01Why W4A4 is hard: outliers crush the grid

A 4-bit format like NVFP4 has only 16 levels — magnitude codes {0, 0.5, 1, 1.5, 2, 3, 4, 6} plus a sign bit. One large outlier stretches the scale so far that every normal value collapses onto the two smallest levels. Below: 256 values (16 blocks × 16), one of them spiked. Drag the outlier and watch both quantization strategies.

Block scales quarantine the damage to the outlier’s own 16-value block.

Block scales fix isolated outliers. They cannot fix a channel outlier — a weight column (or activation channel) that is consistently large across every row and every block. Every block touching that column is degraded, everywhere, at every denoising step. That is the job of the next two moves: smooth_factor and the SVD absorption.

02The trick: smooth, then absorb the hard part into low rank

Per linear layer W [N,K], two things happen offline, at quantization time:

1 · Smooth. Rescale channels to spread outlier energy: x/s on activations, w·s on weight columns — s = smooth_factor [K] lives in the checkpoint.
2 · SVD. Decompose the smoothed weight: W ≈ L + R where L = U·Vᵀ is rank-r (r = 16…64) and captures the spiked, outlier-heavy directions; the residual R is flat and quantizes to 4 bits with almost no error.

W — smoothed weight

L = U·Vᵀ — rank r, BF16

R = W − L — flat, 4-bit

quantize W directly → RMSE quantize R, add L back → RMSE improvement

Synthetic 40×40: gaussian noise + 3 spiked columns + 2 spiked rows (channel outliers, the structure block scales can’t fix). Real SVD via power iteration with deflation, re-run as you drag r. Quantization simulates NVFP4: e2m1 codes with a per-16 block scale, exactly like the checkpoint format.

04Why an extra branch makes it faster

4-bit tensor cores run ~2–4× the BF16 MMA rate on Blackwell. The correction branch costs only 2·r·(K+N) FLOPs against the main GEMM’s 2·K·N — for K=N=4096, r=32, that is ~1.6% of the work. Play with the numbers:

W4A16 relieves memory bandwidth but computes in BF16 — no tensor-core win, which is why it’s the wrong default for compute-bound diffusion. MiniMax-H3 keeps W4A16 only for the 50 low-token AdaLN projections, where bandwidth (not compute) dominates; truly sensitive projections stay BF16.

06What the checkpoint actually contains

From DiffusionSVDQuantConfig.create_weights — every SVDQuant linear carries:

tensorshapedtyperole
qweight[N, K/2]int8/uint84-bit weights, two nibbles per byte (low nibble = even k)
wscales[K/16, N]fp8-e4m3 · NVFP4
bf16/fp16 · INT4		block scales — 16-elem blocks on Blackwell, 64-elem on the INT4 path
proj_down[K, R]bf16V from the SVD — consumes unsmoothed x
proj_up[N, R]bf16U from the SVD — the rank-up
smooth_factor[K]bf16the smoothing divisor s
wcscales[N]bf16per-output outer scale — non-trivial only for QKV, one per Q/K/V shard
wtscale[1]bf16per-tensor outer scale α
nibble k=0 · low
nibble k=1 · high
one qweight byte = two adjacent k values; the converter also half-swaps fused gate-up layers on the N axis so halves land in vLLM’s [gate; up] SiluAndMul order
The fused path folds α ⊙ wcscales into a per-output epilogue vector and pre-divides proj_up by α so the rank correction stays in physical units — the exact math that the head commit of the PR introduced and that the compat epilogue (base·wcscales + x·V·Uᵀ + bias) reproduces for older FlashInfer builds.
