Loader-owned host-weight plans for DLO

One owner for checkpoint semantics: the diffusion loader preflights the checkpoint, hands a single exact HostWeightPlan to the offload backend, and host storage becomes independent of the transfer protocol — so pure-DP workers share checkpoint pages instead of holding private full-model copies.

01

One owner for checkpoint semantics

Before this PR, the loader and the backend each kept their own capability gate and were kept in sync by comments. Now the loader alone decides whether ordinary weight materialization can be skipped, and transfers one exact plan; the backend consumes it or refuses to run — it never re-derives checkpoint decisions.

04

Rank-local runtime pipeline

Per streamed block: pack its mmap views into one staging slot (layout transforms are applied only here), copy H2D into the rotating device slot, and repoint the block's parameters as views into that buffer. Double-buffering keeps one block computing while the next is packed and transferred.
