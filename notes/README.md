# vLLM-Omni Update Notes

This directory is a chronological record of recent vLLM-Omni developments that are
useful to follow between cookbook releases: feature updates, RFCs and design
discussions, notable PRs, performance implications, and open follow-up items.

Notes have **no fixed cadence**. Create one whenever there is a useful set of updates
to capture. Name it by publication date (`YYYY-MM-DD.md`) and state the reviewed
period in its `Coverage` field.

## Publishing a Note

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to `YYYY-MM-DD.md`.
2. Record source links and the status of each RFC or PR.
3. Explain why a change matters; do not restate a title without context.
4. Add the new note to the list below, newest first.
